# 기획 — 매장 키오스크 + AI 고급 렌더링

## 1. 목표
매장 방문객이 키오스크에서 싱크대를 직접 구성하거나, 담당자가 옆에서 하나씩 눌러
보여주며 **그 자리에서 실사급 인테리어 렌더링**을 뽑아 구매 결정을 돕는다.
키오스크에서 결제하지 않고, **QR로 고객 폰에 견적·주문 링크를 넘긴다**.

## 2. 두 가지 사용 모드
| | 고객 셀프 모드(기본) | 담당자 시연 모드 |
|---|---|---|
| 진입 | 대기화면 터치 | 화면 4귀퉁이 롱프레스 + PIN |
| UI | 코치마크 자동, 간편 모드 고정, 큰 터치 타깃 | 전문가 모드(재단표·부속), 가격 조정 표시 |
| 렌더링 | 세션당 2회 제한 | 무제한 |
| 종료 | 3분 무조작 → 초기화면 복귀(구성·장바구니 리셋) | 수동 종료 |

## 3. 화면 플로우 (셀프 기준)
1) **대기화면**: 시그니처 AI 렌더 슬라이드쇼 + "화면을 터치해 시작"
2) **템플릿 선택**: 인기 프리셋 대형 타일(일자 2400 가스대형 등) — 한 번에 완성품 배치
3) **구성 조정**: 3D + 우측 패널(사이즈·소재·장 추가만) — 기존 화면 재사용
4) **✨ 고급 렌더링**: 스냅샷+구성요약 → 이미지 모델 → 15초 로딩(진행 애니) →
   **3D ↔ 실사 비교 슬라이더**, 스타일 3종(모던화이트/우드톤/호텔다크)
5) **마무리**: 견적 요약 + **QR 코드**(구성 ID 담긴 URL) → 고객 폰에서 이어서 주문/상담

## 4. AI 렌더 파이프라인 (기술)
- 캡처: R3F `preserveDrawingBuffer` + `toDataURL` (정면 각도 자동 정렬 후 캡처)
- 프롬프트: `FurnitureInput` → 구성 묘사 텍스트 자동 생성(치수·소재·설비) + 스타일 프리셋
- 생성: `app/api/render-interior` → OpenAI gpt-image-1 **image edit(img2img)** — 구도·배치 유지
- 캐시: 구성 해시 + 스타일 키로 R2 캐시(동일 구성 재요청 무료·즉시)
- 키: wrangler secret `OPENAI_API_KEY` / 일일 한도·요금 모니터링

## 5. 키오스크 운영 요구
- 하드웨어: 24~32" 터치스크린 + 미니PC(또는 고성능 태블릿), 세로/가로 대응
- Chrome kiosk mode(`--kiosk` 전체화면·주소창 없음), 부팅 시 자동 실행
- idle 감지: 3분 무조작 → 상태 초기화 + 대기화면 (localStorage 세션 격리)
- 네트워크 단절 시: 3D 구성은 정상 동작, AI 렌더 버튼만 비활성("잠시 후 이용")
- QR 인계: `/q/{구성ID}` 짧은 URL — 구성 스냅샷을 서버(D1/R2)에 저장

## 6. 마일스톤 (공수 추정)
| 단계 | 내용 | 공수 |
|---|---|---|
| M1 | 스냅샷 캡처 + 렌더 API + 비교 슬라이더 모달 (MVP) | 2일 |
| M2 | 스타일 프리셋 3종 + R2 캐시 + 사용량 제한 | 1일 |
| M3 | 키오스크 모드: 대기화면·idle 리셋·터치 확대·QR 인계 | 2일 |
| M4 | 담당자 모드(PIN)·현장 파일럿·프롬프트 튜닝 | 1~2일 |

## 7. 성공 지표
- 렌더링 1회당 상담 전환율 / QR 인계 → 실제 주문 전환율
- 평균 세션 시간 5분 이내(막힘 없이 완주), 렌더 생성 20초 이내
